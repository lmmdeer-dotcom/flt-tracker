## v1.8.0 习惯 · 年历热力图（已发）

**commit `1a4bd2a` → origin/main**

### 改动
- `index.html` 加 CSS `.hm-*` 块（grid/月标签/legend）
- `v-habits` 拆 pane：原 2 列 → `hmListPane`；新增 `hmYearPane` 装热力图
- 顶部 tab 切换 `列表 / 年历热力图`，模式持久化到 `settings.hview`
- 新函数 `rHabitsYear / setHabitsView / hmJump`

### 数据形态
- 聚合 `T.checks`（owner=curOwner）按 date 计 `perDay[date]=count`
- 起点 = 最早打卡日所在周的周日；终点 = 今天
- 列数 = ceil((today - start) / 7)，自然 1~53 周
- 5 档单色透明度（0=line2, 1~4 = `rgba(192,95,56, 0.4/0.58/0.76/0.94)`）
- lv 判定：count=1→1, =2→2, <total→3, ==total→4
- 未来日期用 `data-fut=1` 占位（半透明 + 不可点）

### 交互
- hover 放大 1.45 + outline（看到哪天打卡数）
- 点击 → `hmJump(dt)`：设 `hDate.value=dt` → 切回 list → `go('habits')` → `rHabits()` 自动重渲

### 关键坑
- `setHabitsView` 调用要放在 `rHabits()` 末尾，否则持久化的 view 不会生效；但要在 setHabitsView 之后再 `rHabitsYear()` —— 用了 `if(v==='year')` 守卫
- 改 cache-bust `?v=1.7.1` → `?v=1.8` 时 sed 把 `1.7.1` 误改 `1.8.1`，再用 perl `\b` 边界修回 `1.8`（sed 无 lookahead/word-boundary 的实用方案）
- 未来日格子必须 `data-fut=1` + CSS `cursor:not-allowed`，否则点击会跳到不存在的 hDate 导致显示"未来"
